# Geräusche

Alle Aufnahmen stehen unter [CC0](https://creativecommons.org/publicdomain/zero/1.0/) (gemeinfrei).
Sie wurden gekürzt, auf Mono gemischt, ausgeblendet und in der Lautstärke angepasst.

| Datei | Verwendung | Quelle |
|---|---|---|
| `clunk-1.wav` … `clunk-3.wav` | Hebel schlägt oben an (Metall) | Kenney, [Impact Sounds](https://kenney.nl/assets/impact-sounds): `impactMetal_heavy_000/001/003` |
| `knock-1.wav` … `knock-3.wav` | Hebel schlägt oben an (Holzgehäuse) | Kenney, [Impact Sounds](https://kenney.nl/assets/impact-sounds): `impactWood_heavy_000/001/004` |
| `payout.mp3` | Ergebnis steht: Münzen klimpern | syncopika, [coin sounds](https://opengameart.org/content/coin-sounds) (echte Münzen), Ausschnitt 6,90–7,80 s |

Alle übrigen Geräusche (Ratsche, Einrasten, Walzen, Sperre) erzeugt `public/app.js` live mit der Web Audio API.
